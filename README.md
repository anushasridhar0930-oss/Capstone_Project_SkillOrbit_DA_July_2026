The main objective of this project is to answer the problem defined in the problem statement by assessing the performance of Nykaa’s marketing campaigns that has caused a consistent growth in its profits. This is shown through the calculation of several metrics. This project also aims to suggest improvements to the campaigning strategies adopted in this analysis to further boost Nykaa’s growth.
A structured, synthetic, real-world inspired e-commerce marketing campaign dataset designed for ROI analysis, performance optimization, and predictive modelling for Nykaa for the period of 01/07/2024 to 24/06/2025. This dataset has been obtained from Kaggle. The variables used in this dataset to compute key

Date                    Time period of campaigning. 
Campaign_ID             Unique identifier for each marketing campaign. 
Campaign_Type           Category of the campaign: Social Media, Paid Ads, Influencer, Email, SEO. 
Target_Audience         Intended audience group for the campaign: College Students, Tier II City Customers, Working Women, Youth. 
Duration                Length of the campaign in days (range: 5–30). 
Channel_Used            List of marketing channels used (e.g., "WhatsApp, YouTube, Instagram"). Impressions Number of times the campaign ads were displayed. 
Clicks                  Number of clicks received on the ads. Leads Number of potential customers created.
Conversions             Number of successful purchases Revenue Total revenue (in INR) generated from the campaign. 
Acquisition_Cost        Cost to acquire customers (in INR). 
Customer_Segment        Specific Segment to which each Nykaa product buyer belongs to. 
Website_Visits          Number of visits to Nykaa’s websites per day 
Indian_Cities           Buyers of different Indian cities influenced by the campaigns.

Using the above variable important KPI have been calculated along with the conduction of trend analysis, campaign performane, customer segment analysis, target audience analysis and city analysis.
The database for this project was created in MySQL workbench. EDA done in Python using Google Colab. Visualization in PowerBi and deployment on Streamlit.
